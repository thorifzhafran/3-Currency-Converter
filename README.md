## 💡 About The Project

I’m Indonesian, living in Malaysia, and often need to spend and receive funds in USD. 

I quickly found it frustrating to use common currency converters that only show a comparison of 2 currencies at a time, requiring constant tab-switching or mental math to see the full financial picture. 

That’s why I built this tool for my own personal workflow. It lets you cross-reference multiple target currencies seamlessly. If you find yourself in a similar cross-border financial situation, feel free to use it!

---

## ✨ Features

- **Simultaneous 3-Currency View:** Compare rates across your core currencies all in one place without recalculating.
- **Fast & Minimalist:** Clean user interface designed for quick, hassle-free everyday conversions.
- **Mobile Friendly:** Access it smoothly from your phone or laptop on the go.
- **Free to Use:** No ads, paywalls, or unnecessary clutter.
